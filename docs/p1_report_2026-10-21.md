# P1 report: pipeline repairs (2026-10-21)

**Scope**: This report documents P1 pipeline changes and offline tests. A passing offline suite establishes behavior under the tested conditions; it does not establish readiness for real-LLM generation, production client integration, or scientifically valid coordination detection. Frozen pilot results and the pre-specified analysis plan remain unchanged.

**Originals:** before editing, copies of the edited files were saved in the session scratchpad (`p1_originals/`), because those files are untracked and git can't restore them.
